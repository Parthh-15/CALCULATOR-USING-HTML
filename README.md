📱 iPhone Style Calculator
A sleek, responsive iPhone-style calculator built using HTML, CSS, and JavaScript.
This project visually mimics the iOS calculator and performs basic arithmetic operations with smooth interactions.
🚀 Features
iPhone-inspired UI design
Responsive layout (centered on screen)
Supports basic arithmetic operations:
Addition (+)
Subtraction (−)
Multiplication (×)
Division (÷)
Additional functions:
Clear (AC)
Toggle Sign (±)
Percentage (%)
Decimal number support
Error handling for division by zero
🛠️ Technologies Used
HTML5 – Structure
CSS3 – Styling and layout
JavaScript (Vanilla JS) – Calculator logic and interactions
📂 Project Structure
📁 iPhone-Calculator
 └── cal.html
All HTML, CSS, and JavaScript are written in a single file for simplicity.
▶️ How to Run the Project
Download or clone the repository
git clone https://github.com/Parthh-15/CALCULATOR-USING-HTML/edit/main/README.md
Open cal.html in any modern web browser
(Chrome, Edge, Firefox, Safari)
